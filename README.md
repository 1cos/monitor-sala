# Monitor sala

Slideshow delle foto dei piatti e della cheese wheel per il TV della sala (progetto STUPIDO S-05).
- `index.html`: slideshow (8 s per foto, zoom lento, dissolvenza, 1 cheese wheel ogni 5 piatti). `?info=1` mostra sempre il riquadro della memoria.
- `sw.js`: tiene le foto nella memoria del TV.
- `lista.json`: elenco delle foto. `foto/`: versioni Full HD (gli originali restano sul disco WD).
